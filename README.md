## Visão geral

Website institucional desenvolvido sob medida para **Leonardo Mendonça
Silva**, Engenheiro Civil especializado em Engenharia Diagnóstica e
Consultiva.

O projeto foi desenvolvido com o objetivo de estabelecer uma presença
digital profissional, apresentar os serviços oferecidos e fortalecer a
identidade visual do cliente por meio de uma experiência de navegação
moderna, intuitiva e responsiva.

## Demonstração

**Acesse a versão publicada:**

portifolioleonardosilva.netlify.app](https://portifolioleonardosilva.netlify.app/)

## Funcionalidades

- **Página inicial:** apresentação profissional e destaque dos
  principais serviços.
- **Sobre:** trajetória, experiência e formação profissional.
- **Serviços:** apresentação das soluções em Engenharia Diagnóstica e
  Consultiva.
- **Métodos:** descrição das metodologias e abordagens de trabalho.
- **Contato:** formulário interativo para preparação de mensagens por
  e-mail.
- **Menu responsivo:** navegação adaptada a dispositivos móveis.
- **Layout responsivo:** adaptação dos elementos visuais a diferentes
  tamanhos de tela.

## Implementações técnicas

### Interface e responsividade

Desenvolvimento de layouts utilizando CSS Grid, Flexbox e Media Queries,
além de variáveis CSS para padronização de cores e propriedades visuais.

### Navegação interativa

Implementação em JavaScript do menu mobile, com abertura e fechamento
dinâmicos e encerramento automático após a seleção de um link.

### Formulário de contato

Utilização da API FormData para capturar e organizar os dados
preenchidos. A mensagem é preparada por meio do protocolo `mailto:`,
permitindo que o visitante conclua o envio pelo aplicativo de e-mail.

## Como executar localmente

**1. Clone o repositório:**

``` bash
git clone https://github.com/HiLucasSilva/portifolio-leonardosilva.git
```

**2. Acesse a pasta do projeto:**

``` bash
cd portifolio-leonardosilva
```

**3. Execute localmente:**

Abra o arquivo `index.html` no navegador ou utilize a extensão Live
Server no Visual Studio Code.
